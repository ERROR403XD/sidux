# 自动化界面与会话完成蓝点调整

## 范围与实现

- 分支：`feature/0.2.17-development`，版本保持 0.2.17。
- `473f422`：自动化列表以 AppSwitch 替换编辑按钮；只在启用且有下次执行时间时展示时间。去掉列表名称下的任务类型与详情副标题，长名称保持单行省略。详情移除提示词预览，在编辑左侧加入 AppButton 移除按钮，保留运行历史和编辑入口。
- 列表启停保持当前位置：首次加载/显式刷新记录排序，写入后的数据刷新保留 rowKey→位置映射。只有刷新页面或点击刷新按钮才重新按启用优先和时间排序。额外空间 O(n)，无新增请求；自动化 JS 增加约 0.23 kB（gzip 约 0.09 kB）。
- 启停沿用现有项目/会话 PUT 接口，保留模型、账号、保护、时区等字段；移除沿用 DELETE。等待期间禁用，失败保留旧状态并显示错误。成功后并行刷新三份自动化数据，将同份映射同步到侧栏，不重复请求。
- `1f443a2`：完成通知到达时，仅在当前会话选中、实际会话路由匹配、document.visibilityState 为 visible 时提交已读确认。隐藏页面、设置页或后台会话保留未读。已读携带当前完成 token，同 token 的在途确认合并，旧响应不能清除新回合。

## 性能与限制

每组自动化核心验收共 4 次 PUT（含一次失败）和 3 次 DELETE（含一次失败）；排序补充验证另有 2 次 PUT 检查首行启停保持位置，并检查页面刷新/工具栏刷新重新排序，未出现重复提交或 JS 错误。新交互无新增轮询、全量会话请求或无界并发；自动化仍使用原排序与响应体，去掉提示词 DOM 降低渲染量。蓝点确认 Map 随请求结束清理。相对自动化 UI 提交，蓝点逻辑令主 JS 增加约 0.30 kB、gzip 约 0.14 kB。

未测量真实调度延迟、跨设备网络延迟；本次不改后端调度与模型执行。

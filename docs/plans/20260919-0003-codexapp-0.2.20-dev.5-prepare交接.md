## 2. 高级选项为什么会丢（根因，已用证据确认）

dev.3 与 dev.4 不是同一条线上的版本，而是 `f48e01d`（0.2.20-dev.1）之后的两条平行分支：

| 检查项 | 结果 |
| --- | --- |
| `git merge-base 9395d7c dbd2f6b` | `f48e01d`（dev.1），**不是** dev.3 |
| `b2fa900` 是否为 `9395d7c` 的祖先 | 否 |
| `9395d7c` 是否为 dev.4 的祖先 | 否 |
| `f48e01d` 的 `ApiProxyPanel.vue` 含 `openAdvanced` | 0 处 |
| `9395d7c`（dev.3）的 `ApiProxyPanel.vue` 含 `openAdvanced` | 3 处 |
| dev.4（NAS `dbd2f6b`）的 `ApiProxyPanel.vue` 含 `openAdvanced` / `强制路由` | 0 处 / 0 处 |
| dev.4 相对 dev.1 改了 `ApiProxyPanel.vue` | +24 / −7 行（端点 tag、通知），**未含**高级选项 |

即：外部开发从 `f48e01d` 起分支，dev.3 的高级选项提交（`ced9558`…`9395d7c`）从未进入 dev.4 的血缘，所以「clone 到 dev4 时没带出去」。

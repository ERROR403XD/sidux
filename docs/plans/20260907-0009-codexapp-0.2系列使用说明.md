# CodexApp 0.2 系列使用说明

当前候选地址为 `http://192.168.50.46:59001/`。侧栏底部应显示 `v0.2.9`。生产 5900 的版本仍为 0.2.0；本说明中的新增功能以 59001 为准。

## 显示时区与日常输入

侧栏底部打开「设置」→「显示时区」，搜索并选择 `Asia/Shanghai`、`America/New_York`、`UTC` 等，也可选择「跟随系统」。设置立即应用于日期显示，刷新后保留，同源标签页同步，不再在每条时间旁重复标注。

这个偏好属于本浏览器当前站点，应用内各页面和账号共用。另一设备、浏览器或端口需要单独设置。浏览器禁止保存时会显示错误；原设置继续生效。自动化的「调度时区」决定任务何时执行，与显示时区分别设置。导出的独立 Markdown 保留导出时区，便于离开应用后阅读。

代码块右上角「复制代码」复制原始代码；回复的复制按钮保留 Markdown。复制失败可重试。会话切换和刷新会恢复各自草稿；提交前仍可检查内容。侧栏中的发送快捷键设置决定 Enter 的行为。

## 问题、审批和发送状态

异步问题显示在对应消息卡片中。可以先「暂不回答」并继续聊天，之后展开回答；默认选项不会自动提交。自由文本答案在该卡片填写，点击「发送回答」后与具体问题绑定。直接在普通输入框聊天不会被猜作答案。

阻塞提问与命令审批需要先处理，审批优先显示。回答失败会保留输入以便重试；刷新后读取待处理状态。凭据恢复提示仅说明正在尝试恢复，结束后以实际回合结果为准。

| 发送状态 | 建议操作 |
| --- | --- |
| 排队 | 等待，或使用该条消息的编辑、重排、移除操作 |
| 正在发送 | 等待结果，避免重复创建同内容消息 |
| 已接受 | Codex 已接受该次发送；任务是否完成仍看回合结果 |
| 结果不明 | 先核对状态和会话最新内容；系统不会直接重发 |
| 发送失败 | 查看错误，修正条件后按界面提示处理 |
| 编辑冲突或账号变化 | 刷新该条记录后再操作，避免覆盖另一页的修改 |

未确认发送保存在本浏览器；服务端队列保存在候选的独立状态目录。清空浏览器数据会失去本地草稿和未确认记录，不是处理发送异常的方法。

## 历史、搜索与分支

进入会话先读取最近 10 个回合，向上加载更早内容。加载失败可重试，已有内容保留。历史中的图片、技能、文件链接和异步问题仍可查看；从回复分支使用该回复的真实回合边界。

搜索会显示覆盖范围。标题最多检查 1000 个会话；正文最多检查最近 100 个会话、每个最近 50 回合，并受单会话正文大小限制。未找到结果不表示全部历史一定不存在。重命名、归档和取消搜索会使相关结果更新，迟到响应不会覆盖新查询。

当前 CLI 的原生分页历史不支持应用中的旧式撤回操作；界面会阻止并保留草稿。可根据需要从明确的回复建立分支。

## 持续目标与上下文压缩

通过 `/goal` 打开目标窗口，填写目标及模型、推理强度和可选预算。预算不填表示不设预算；没有单位时按 M 计算，`1M` 为 100 万 tokens，`1B` 为 10 亿 tokens，`0.001M` 为 1000 tokens。

「保存目标」保存修改；「继续目标」明确恢复执行。修改预算不会自动清零已使用量，也不会自动解除阻塞。预算耗尽时先提高或移除预算再继续。目标被阻塞时查看最后回复并处理原因；更多计量和暂停行为可展开「预算与暂停说明」。用量取自 Codex，不把普通会话累计量或猜测的子任务用量混入目标计量。

通过 `/compact` 请求压缩上下文。进度、完成、失败或中断会显示在消息中；刷新后尝试恢复。结果不明时先检查状态，不自动重复压缩。压缩保留哪些内容由原生 Codex 决定，应用不把它当作完整历史备份。

## 子任务和任务引用

会话中的「子任务」显示父子关系、角色与原生状态。点击子任务进入对应会话，可返回父任务。尚未载入或不可用的任务会明确显示；创建子任务的工具调用结束不代表子任务工作已经完成。

任务搜索可按标题或已索引正文查找。需要把其他会话内容交给当前模型时，选择任务并明确附加摘录；关闭窗口不会自动插入。摘录最多取最近 10 回合、6000 字符，不能代替完整会话。仅有 `thread://` 链接不保证模型能读取其内容。

## 技能、插件、应用与 MCP

从会话进入扩展目录时，可保留该项目和会话的查看范围；也可切换到全局。相同名称的技能按实际路径区分。项目可见不代表安装或启停一定写入项目：操作按钮会说明用户设置范围，项目已有技能不会提供误导的用户目录卸载入口。

| 状态 | 含义 |
| --- | --- |
| 已安装 | 本机存在相应扩展 |
| 已启用 | 配置允许使用 |
| 已登录 | 认证状态已建立 |
| 已连接 | MCP 运行连接已建立 |
| 可调用 | 当前运行快照列出了可调用工具 |

这些状态可能不同，不能只凭「已登录」判断能调用工具。变更后目录会重新读取状态，MCP 配置重载需要明确点击。完整工具与资源详情按需读取。外部 App 目录失败时，会保留错误和可获取的运行快照；这不代表外部目录或 OAuth 已恢复。

## Hooks 与后台终端

「Hooks」用于查看当前会话收到的 Hook 事件、耗时、结果与配置来源。它是观察记录，未收到的历史不会凭空补齐。服务重启后没有最终结果的旧记录显示未知；配置需要信任或调整时，在对应 Codex CLI 环境处理。

「Codex 后台终端」显示原生后台命令。展开某条记录查看已收到或能有界读取的输出片段；片段可能截断，不等于完整 stdout。停止时先选中具体命令，再确认「停止此进程」。取消不停止，停止结果不明时先刷新，其他命令继续保留。

主回合完成后，后台命令可能仍在运行。存在后台命令时，账号／供应方切换及候选替换会被阻止；需要先明确处理对应命令。

## API 出口

侧栏「API 出口」使用蓝色入口。选择 API 使用账号并保存；它可以与 WebUI 当前账号不同。已有请求如何结束以界面的等待与连接状态为准。

「创建 key」窗口将名称和「持续时间（天）」分行显示。持续时间留空为无限，填写正整数表示天数；`0`、负数、小数和过大数字会被拒绝。完整 key 仅在创建时显示，保存到实际客户端配置中。撤销 key 后不能继续发起新请求；已开始的响应按现有规则结束。

## 验证范围

本版本已通过桌面、375×812 和 768×1024 的浅深主题回归，以及浏览器模拟的中文 composition、软键盘高度和复制失败检查。真实手机输入法、真实第二账号切换、自然令牌到期和外部 OAuth 成功链路尚无本轮实测证据。

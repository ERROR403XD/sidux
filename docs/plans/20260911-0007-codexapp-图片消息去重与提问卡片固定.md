# 图片消息去重与提问卡片固定

## 结果与范围

用户确认 Windows Chrome 的 5900 输入框展开问题在刷新后消失。Chromium/WebKit 的桌面/手机尺寸测试能正常变高；本轮不修改既有展开尺寸、定位或 CSS。Windows 系统本机没有直接运行，浏览器补验使用 Linux Chromium 加 Windows UA，不能替代用户设备复测。

- `d6d7bbd`：跟随系统主题图标替换为 monitor 显示器轮廓，保留手动深浅色图标及切换逻辑。
- `83fd26e`：修复带图片发送后出现两份文本/图片的问题。原生 userMessage 的 clientId 现在映射到前端发送 ID，作为占位消息与真实回显匹配依据；兼容旧 clientUserMessageId。缺少发送 ID 时，按同 turn/消息序号核对文本，归一化图片 URL，并排除图片自动附带的同路径文件 chip；不同 ID/序号的真实重复消息不合并。
- `935deba`：异步提问卡片移至输入框上方的独立待答区域，不随历史滚动。区域有高度上限及内部滚动；回答失败保留卡片和重试入口，成功后移除，历史回答仍保留。按会话、turn、问题序号隔离，切换会话重建局部状态。

没有更改原生发送次数、调度、账号路由或协议提交逻辑。

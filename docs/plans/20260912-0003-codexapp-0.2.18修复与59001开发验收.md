# CodexApp 0.2.18 修复与 59001 开发验收

## 范围与实现

本轮用户授权在 59001 开启 0.2.18，修复 0.3 展望配套小版本计划中的 R01/R02，增加会话功能提示关闭，并将 S05 做成轻量“已保存”。随后另做 0.3 UI 草案。

| 项目 | 结果 |
| --- | --- |
| R01 反馈入口 | 旧邮箱和 mailto 构造已移除。现有入口打开共享 AppDialog，预览/编辑/复制最小报告；用户可自行打开当前项目 Issues |
| 采集范围 | 只导出版本、时间、页面类别、主题、界面语言、视口、错误类别和 HTTP 状态。最多 12 条诊断；不读页面文字或存储，不导出原始错误、路径、URL、会话正文 |
| R02 额度文案 | QUOTA_EXHAUSTED 保持不变，文案改为查看实际额度与恢复时间、恢复后再试；保留认证/网络等分类及原调度行为 |
| 功能提示关闭 | 历史操作、队列功能错误和命令错误增加 ×，只收起本次提示。再次发生错误仍可显示；不修改持久失败回合或审批状态 |
| 命令反馈 | `/copy` 等直接命令的功能错误有独立输入框上方提示；按会话上下文隔离，旧会话异步结果不会写到其他会话 |
| S05 | 现有 localStorage 写入成功后显示轻量“已保存”，清空后消失；失败显示“保存失败 / 复制草稿”，复制不可用时选中输入。未增加存储动作、网络请求或保存流程 |

草稿文字复制不备份附件二进制；附件仍沿用已有持久化引用。同步存储没有额外引入“保存中”的人工延时或动画。

## 后续界面精简与统一时间控件

按照用户两次截图反馈，四处统一为与自动化每日时间相同的带时钟图标原生 `type=time` 控件：POST 免打扰、Telegram 免打扰、每日账号激活、自动化每日时间。不是早期讨论的纯文本框；展示格式由浏览器地区设置决定，保存仍为 HH:mm。

移除了设置及账号弹出区的“尚无账号，请从此面板添加。”、无账号时的模型偏好差异提示、关于页工作树，以及自动化正常运行的调度器文案。异常、初始化和交接中的调度器提示继续保留。

免打扰时间框固定为 96px，激活时间为 104px；开关标签间距 12px，开关与时间组间隔 20px。窄屏自然换行。原生选择器保持可用，中文冒号及全角数字粘贴通过共享解析统一为标准时间；非法粘贴不覆盖已有值、不保存，自动化空时间也不能默默变成零点。

验证：`pnpm run build` 通过；时间解析、激活调度、Telegram 配置及翻译相关 4 文件 32 项测试通过。4173 中文覆盖 1440×1000、375×812、768×1024 明暗主题；59001 英文覆盖 1440×1000、375×812 深色，均通过原生控件类型、开关不重叠、窄宽度、零横向溢出、保存刷新恢复、中文冒号/全角数字归一化和非法粘贴无保存请求的断言。实际账号弹出区也核对空提示已移除。浏览器页面异常为零。

浏览器读写均使用合成配置和路由拦截，未触发真实通知或账号激活。32 项为本次相关测试，并非重复全量回归。原始证据位于 `/home/Code/codexapp/output/0218/time-ui.json`、`time-candidate-ui.json`、`time-tests.log`、`time-build.log`。

性能：不新增 API、轮询、全局监听或定时器；共享组件只处理自身原生事件，激活保存沿用原有 400ms 合并逻辑。4 个通知输入框和激活/自动化输入按现有页面生命周期挂载。主入口 816.68 KB / gzip 259.07 KB，相对上一版增加约 0.40 / 0.20 KB；未重测首页或长会话性能。未更改服务端运行逻辑。

### 新增自定义连接误报切换

原因：新增配置保存曾无条件调用 `beginProviderChange()`，而该检查的 `isAccountOperationInProgress()` 同时涵盖后台额度/凭据刷新。因此，即使没有手动切换账号，检测端点成功后保存也可能被拒绝，并显示误导的“账号或供应方正在切换”。

修复仅让**新增配置**绕过提供方切换检查；已有连接的切换、编辑、移除及使用中保护保持原路径。新增仍通过配置存储自己的串行写队列，不改主账号凭据，也不自动选择新连接。真实 HTTP 中间件回归保持 OpenAI 额度刷新未结束、确认没有切换阻塞，完成三端点测试和落盘保存，再核对主凭据、OpenAI 选择、自定义选择均不变；同时确认提供方选择仍受原检查约束。

```bash
pnpm exec vitest run src/server/customConnectionAdmission.test.ts src/server/customConnectionStore.test.ts src/server/deliveryBridge.test.ts src/server/accountRuntimeIntegration.test.ts
```

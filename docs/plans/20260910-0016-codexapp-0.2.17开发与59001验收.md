## 已完成

- 插件目录同时维护磁盘快照和页面缓存；启动预热，当地时间每日 02:00 内部刷新。手动刷新位于“全部插件”左侧，增加可搜索页码选择器，每页最多 60 张卡。读取合并、磁盘写入串行、最多 12 个项目范围；上游部分失败保留最近完整快照，自动失败重试有一分钟退避。
- 目标窗口删除指定说明和预算折叠说明。无单位预算按 1 token，支持 k/M/B；中文占位符为 `100、2k、30M、0.4B；留空不设预算`。用整数算法处理缩写，避免大数精度丢失。修复 Thinking 活动标签与推理强度设置混用的问题。
- 定时激活即时保存，账号和时间分栏，下方显示下次计划。按账号串行创建私有 CODEX_HOME 与空目录，显式注入固定账号凭据、发送 `hi`，等回合完成后延迟 120 秒，结束专属进程并删除全部私有数据；不使用共享登录文件，不刷新目标凭据，不更改主账号选择。去掉保存计划、刷新结果按钮。
- “自定义连接”与 OpenAI 账号平级，提供卡片、别名和统一添加/编辑窗口。提供 OpenRouter、DeepSeek、OpenCode、自定义 Base URL；支持模型目录及手动模型名。密钥单独保存，卡片及列表不返回密钥。
- 测试连接分别探测 `/v1/models`、`/v1/responses`、`/v1/chat/completions`，保存成功端点，再次测试可刷新模型和能力。仅支持 Chat 的卡片显示“仅 API key 出口”，切换禁用，也不进入 Codex 自动化账号选项。API key 可选择它，只开放通过检测的接口；未支持的端点返回 404，不转为另一种协议。当前不开放自定义连接 compact/WebSocket。
- 支持 Responses 的自定义连接可用于对话、目标、自动化和 API key。运行进程按连接绑定，使用独立内部凭据与版本地址；真实上游密钥不进入进程参数。OpenAI 协调器的凭据选择、配额保护、出口和切换约束沿用原路径。
- 没有明确 reasoning/Fast 能力时，模型控件显示 N/A，滑条灰化且不可拖动；目标、自动化及默认设置的对应选择禁用。若模型声明能力，使用其原始值；缺失能力的参数在最终出站时也会剔除。
- 侧栏左上角恢复绿色闪电“应用 / 插件 / 技能 / MCP”；集成去掉重复入口。POST 与 Telegram 平级，精简说明，POST 保存/测试位于免打扰上方；Telegram 两个文本框、两个按钮，授权 ID 占位符第三行为 `*`。调整各处布尔控件为 toggle switch，中英文同步。

开发过程中修复了原生自定义会话测试发现的热重载问题：保留的执行桥与新中间件曾持有不同连接存储。现在按 CODEX_HOME 共享存储身份，并更新执行桥版本；新增模块重载回归测试。

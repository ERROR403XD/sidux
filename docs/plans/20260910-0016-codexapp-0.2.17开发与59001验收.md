# CodexApp 0.2.17

开发分支 `feature/0.2.17-development`，起点 `1f35011`。候选端口 59001，独立数据卷 `codexapp-multi-account-dev-home`；不操作生产 5900 的运行配置、账号及登录态。

## 范围与验收

1. 插件目录磁盘与页面缓存、当地每日 02:00 内部刷新、手动刷新移至筛选左侧、可搜索页码选择器。
2. 目标窗口删除指定说明；无单位预算按 1 token，支持 k/M/B，精确整数转换。
3. 定时激活使用指定账号凭据建立隔离的无工作区会话，发送 `hi`，完成后延迟约两分钟清除；串行调度、不切换登录态；设置即时保存及两栏布局。
4. 自定义连接独立账号卡与添加/编辑窗口；别名、提供方/base URL、API key、模型、连接测试；接入会话、自动化、API key 路由，保持 OpenAI 账号隔离与切换约束。
5. 修正 Thinking 活动标签；缺少模型能力时，自定义连接推理强度和 Fast 禁用，会话推理滑条显示 N/A；支持时使用提供方能力，能力值保留原文。
6. 侧栏应用入口、POST/Telegram 平级通知设置、统一开关与中英文精简文案。

## 验证进度

开发中，尚未部署 0.2.17，不将静态检查或容器启动视为完整验收。账号、激活、外部 API 和通知优先使用隔离样本与本地模拟服务，不消耗真实重置机会，不发送真实测试通知。

# CodexApp 0.2 版本功能说明

## 版本与使用边界

本文说明 **0.2.18 候选**的现有功能；2026-09-12 本轮结束时生产 5900 仍为 0.2.17，59001 为独立开发环境。prepare 已完成，未启用到生产。旧的 0.2.9 使用说明保留历史状态，当前说明以本页为准。

CodexApp 在浏览器中操作主机 Codex，会话、文件和终端实际在服务主机运行。浏览器不是独立执行器。原生 CLI 能力不同会影响可用功能：显示不可用或需要分支等提示时，应根据当前界面处理，不用重复发送绕过限制。

## 项目与会话

从首页选择主机目录，或明确创建/导入项目，再开始会话。项目与会话当前仍以侧栏管理；同一项目可以有历史会话，但应用不要求多个会话同时协同。

项目多目录用于提供项目上下文。受管信息写入项目 AGENTS.md 的指定标记块，用户其他内容保留。会话记录和主机目录是不同对象，归档会话不等于删除项目文件。

完成标记用于找到新完成工作；清除标记只确认当前完成记录。正在查看的会话完成时不再额外产生蓝点。置顶、完成、运行状态各有语义，不能只用颜色判断任务是否成功。

## 输入、草稿与发送

输入框按当前会话恢复草稿；保存成功时轻量显示“已保存”。该提示仅表示草稿保存成功，不表示消息已发出、服务端已接受或任务已完成。保存失败时保留输入，使用复制退路。草稿随浏览器来源保存，清除站点数据会丢失它。

模型、推理强度、Fast 等控件按当前连接能力显示；不支持时禁用或显示不适用。已经保存的偏好不应被无账号时的临时 fallback 文案反复覆盖。技能/文件选择只附加到草稿，不自动发送。

| 状态 | 含义与操作 |
| --- | --- |
| 排队 | 尚未发送；可以按界面编辑、调整顺序或移除 |
| 正在发送 | 已进入提交阶段；不要通过新建同内容消息代替核对 |
| 已接受 | 上游接受此次发送，最终成功仍看回合结果 |
| 结果不明 | 发送结果无法确认，先核对会话和发送记录；系统不会直接自动重发 |
| 发送前失败 | 检查目录、模型、账号、连接或参数后处理 |
| 编辑冲突 | 记录已变化，刷新后操作，避免覆盖另一个页面的修改 |

显式“插话”与普通排队不同，按当前回合能力处理。队列以服务端投递台账为准，浏览器刷新不会授权重复发送。旧发送 ID 有保留周期，不应把很久以前的 ID 作为永久外部幂等协议使用。

## 问题、错误与审批

未回答的问题固定在输入框附近，相关回合仍可查看。异步问题可暂不回答，之后回到卡片答复；默认选项不会自动提交，自由聊天不会被猜作问题答案。审批需要明确操作。

会话上方的功能性红色提示，例如复制/分支能力限制、命令或队列操作错误，支持 `×` 关闭。关闭只收起提示，不解除限制、处理审批或删除失败回合；新消息出现时仍可再次显示。持久的失败回合保留，用于刷新后核对。

额度或速率限制提示查看当前额度和恢复时间；认证问题提示检查账号。应用不会把换账号作为绕过额度或限制的修复方法。

## 历史、搜索、分支和导出

进入会话先取最近部分历史，向上按页加载；已有内容不因更早一页失败而清空。原生分页不支持的操作会明确反馈。分支应对应选中回复的真实回合边界；无法复制或撤回时可按界面支持的方式创建分支。

搜索显示覆盖范围：标题最多 1000 个会话，正文最多最近 100 个会话、每个最近 50 个回合，并受正文大小/运行时间边界约束。没有结果只表示已扫描范围内未找到。

代码复制获得原始代码，回复复制保留 Markdown；导出的独立文档注明导出时间/时区。外部打开文件或导出前，应确认内容适合分享，应用不会替用户自动脱敏全文。

## Goal、压缩、子任务与额度续跑

`/goal` 管理原生目标，可设置模型、推理强度和可选预算。保存与继续是不同动作；预算不填表示不设预算。`M` 为百万 tokens、`B` 为十亿，具体输入提示以界面为准。提高预算不自动清零已用量，也不保证解除原生阻塞。

`/compact` 请求上下文压缩，展示原生进度和最终状态；结果不明先核对，不重复触发。压缩不等于完整历史备份。

子任务入口展示父子关系和原生状态，工具调用返回不表示子任务工作完成。引用其他任务时明确附加摘录；摘录只包含有限最近内容，不能当作完整会话传递。

额度恢复续跑保存“恢复后继续”的意图，检测到条件允许才经发送台账提交。它不修改账号，也不取消供应方限制。当前审阅发现超过八条等待记录时的公平性缺口（SCH-04），少数尾部会话可能迟迟未被检查；整改前不能据此承诺所有等待会话及时恢复。

## 自动化：会话推进与项目计划

会话自动化持续向指定会话提交任务；项目自动化按配置目录创建执行会话。二者由服务端调度，关闭浏览器不会停止计划。服务必须保持运行，计划与账号/连接配置有效。

新建或编辑自动化时，填写名称、提示词、执行目标和计划。选择“每天运行”后可用“添加时间”增加时刻，每行可移除；保存时去重并排序，最多 24 个。新建和编辑使用同一形式，保存后刷新应保留。

例如加入 **08:15、18:45**，每天只触发这两次，不额外产生 08:45 或 18:15。规则在后端按精确时刻保存。高级规则只支持已列明的分钟/小时/日/周频率及部分字段，不是完整无限制 RRULE 编辑器；不能转成每日列表的约束继续保留在高级模式。

时间输入是带时钟入口的单个控件。可粘贴 `09:00`、`09：00` 或全角数字并归一化为 HH:mm；无效时间不会作为有效计划保存。浏览器可能按系统地区显示 AM/PM，保存格式仍为 24 小时。

| 运行状态 | 含义 |
| --- | --- |
| queued / 排队 | 等待目标、账号或运行槽 |
| starting / 准备中 | 正在准备，或提交结果待核对；不能直接当作没发送 |
| running / 运行中 | 上游回合正在执行 |
| waiting_input / 等待输入 | 需要问题答案或审批 |
| completed / 完成 | 对应执行回合完成 |
| failed / 失败 | 执行失败，打开会话处理 |
| interrupted / 中断 | 服务/上游中断，或无法确认结果 |
| missed / 漏跑 | 超过补跑窗口，需要时手动处理 |
| skipped / 跳过 | 已有待执行或多个漏跑合并等 |
| cancelled / 取消 | 定义变更、账号移除等导致取消 |

列表开关控制后续计划；立即运行是单独操作，可对暂停计划手动执行。当前 active 并发上限为 4。同目标繁忙时保留有限等待，多次漏跑合并最近时点，超过 24 小时的最近漏跑记 missed，不无限回放历史。

计划实际使用服务端保存的 IANA 时区。显示偏好、浏览器系统时区和服务端执行时区不应靠猜测视为一致；修改相关设置后核对“下次执行”。夏令时不存在的本地时刻跳过，重复时刻执行一次。

## 账号、自定义连接和定时激活

账号卡片与设置提供账号信息、额度和连接管理。执行中的会话持有其实际账号；切换界面选择并不保证正在执行的回合改用新身份。移除账号会影响该账号的连接和任务，按界面明确处理。无账号不重复展示“尚无账号，请从此面板添加”等提示，也不追加 fallback 模型说明。

自定义连接由用户设置端点、模型与协议；Codex 执行要求兼容 Responses API。可用性以实际连接与模型能力为准，保存配置不等于远端验证成功。

“定时激活”默认关闭，选定账号及每日时刻后保存。最多 24 个时间，添加/移除方式与自动化每天运行一致。到点时要求账号可用、不忙碌、获得最新额度，存在真实 300 分钟窗口且该窗口 usedPercent=0；不符合立即跳过。准备前后均核对，前台工作优先。

激活使用最小 API 请求，不建立用于工具执行的普通会话；不自动换账号、不补发停机期间时刻，发送结果不明不自动重发。“已发送”只说明请求完成；额度窗口是否启动要看后续额度事实。激活记录按时刻分页，保留约三个月。本轮没有用真实账号确认实际额度效果。

## 通知、扩展、API 与开发工具

POST 和 Telegram 通知各自配置渠道、规则和免打扰。免打扰开关及起止时间分组显示；跨午夜的时间段可保存，发送按渠道规则延后/处理。“测试”会发送测试消息，只应由用户明确点击；本轮审阅没有执行外部发送。通知结果不明不自动重发，不能把它当作保证送达的告警系统。

扩展目录区分安装、启用、认证、连接和当前可调用状态；目录加载失败不会证明已安装工具消失。详情按需加载，MCP 重载和安装/卸载均为明确动作。相同名称不同路径的技能是不同实体。

API 出口独立管理 key、账号/连接、模型、HTTP/SSE/WS、活动与用量。完整 key 仅在创建时提供，保存到实际客户端；保护值和 fixed account 决定准入，不自动把请求分发到其他账号。管理页能打开不表示 `/v1` 可无 key 调用。

App 内交互终端与 Codex 原生后台终端不同。停止后台命令前核对具体记录；processId 是工具标识，不能当成 OS PID。主回合完成后仍可能有后台命令。Hooks 页显示收到的观察记录，不补造未接收的历史。Git 和文件编辑作用于服务主机实际项目。

**当前文件预览存在 SEC-01 同源主动内容风险**：HTML 脚本可能调用管理接口。此项已经使用临时文件复现，待隔离修复；不要把预览面板当作不可信内容的安全沙箱。

## 设置、反馈和验证说明

界面支持中英文、浅深/自动主题、显示时间和会话默认设置。关于页显示用户有用的版本信息，去掉“工作树 codexapp”；自动化健康时不展示“调度器：运行中”，异常仍可见。

反馈打开最小报告，可预览、编辑、复制后自行提交 Issues；不自动包含页面 DOM、localStorage、会话正文、绝对路径和认证信息。复制完成不等于已经提交反馈。

本轮全量 706 项测试通过、1 项跳过，发布包/真实 PTY/缓存升级已验证；此前 0.2.18 UI 变更有浅深及三种视口证据。真实 OAuth、云端激活、真实手机输入法和长期大历史性能未由本轮覆盖。[发布交接](20260912-0005-codexapp-0.2.18发布准备与审阅基线.md)与[审阅报告](20260912-0006-codexapp-0.2系统代码审阅.md)分别说明可交付范围和已知问题。

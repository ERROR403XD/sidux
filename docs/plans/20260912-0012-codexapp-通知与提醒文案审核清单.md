# 通知与提醒文案审核清单

此次按当前 0.2.18 开发工作区盘点，包含正在开发的操作 Toast、分支即时显示与筛选保留修正。遍历 src 下 231 个非测试 TypeScript/Vue 文件，汇总去重后 **1044 条可枚举的文案与消息模板**。包含前端、后端错误兜底、命令行提示和功能说明；不是说这些文字全部都应变成 Toast，也不是说它们都会在正常操作中出现。本轮实现已更新到 59001；代码基线为 4d9fae3，中文审核译文仅存在于本文和 CSV。

可直接在“审核意见”列填写替代文本，或反馈编号，例如“NT0001 改为……”。相同原文合并来源，不把同一句话的不同出现位置重复编号。每条保留源码原文、中文与出处；本清单不会修改产品文案。

## 审核约定

- 用户操作失败：Toast 通知“未做成”，包括该次操作请求失败。
- 用户重要操作成功：Toast，例如创建分支、设置目标、切换账号、保存/移除自动化。
- 系统自动加载、后台同步、运行时依赖错误：保留原位置，不能靠超时隐藏来掩盖功能受限。
- 对话内的上游响应、回合失败与额度不足错误：保留在对话中，不使用 Toast。
- 确认对话框、权限审批、等待用户输入、表单约束和持续状态：单独审核，不能因文字像“提示”就全部改成 Toast。
- 分类按来源和用途归组，具体错误可能被不同调用路径共用；不能按“失败/成功”关键词决定呈现方式。
- “中文审核译文”是为审核英文源码消息提供的中文解释，**尚未写入产品**。其他中文来自源码或现有翻译表；上游原样内容不执行全局翻译。
- {变量1} 等表示运行时值，源码位置可查原插值；{threadId} 等原生占位符保持不变。
- 此表是可静态枚举文案清单，动态异常内容、第三方工具输出、运行时命令的标准错误以及用户输入无法穷举，见末尾 DT 类。普通导航标签、纯 CSS/协议标识与测试样本不作为通知文案。

## 无法预先枚举的动态消息类型

以下列出类型与来源规则，不伪造具体报错内容。

| 编号 | 类型 | 内容来源与审核边界 | 呈现规则 | 审核意见 |
| --- | --- | --- | --- | --- |
| DT01 | 模型/提供方回传错误 | 上游返回的 error/message、HTTP 状态及详细说明；内容随提供方、模型和请求变化 | 对话内原样保留，不转 Toast | |
| DT02 | 回合中断、额度不足 | 最终回合错误与账号额度状态，可能包含重置时间、提供方原因 | 保留对话错误；“忽略”仅影响筛选资格，当前选中会话暂时保留 | |
| DT03 | 用户操作的 HTTP/RPC 失败详情 | 该次点击、提交、保存对应请求返回的 message，静态兜底见 NT 条目 | 操作 Toast；不按 HTTP 502 等字样一刀切 | |
| DT04 | 系统自动加载/同步失败详情 | 自动读取目标、会话、队列、账号、模型目录、运行时等失败 | 持续错误区及原有重试入口 | |
| DT05 | CLI、Git、PTY、文件系统错误 | 系统异常、退出码、stderr、文件路径和命令信息 | 根据触发方区分操作失败与系统错误；保留诊断上下文 | |
| DT06 | 工具、MCP、插件、Hook 输出 | 外部工具返回的文字、错误及诊断 | 原有工具/会话/状态区域，不能统一重写 | |
| DT07 | 自动化执行记录 | 单次运行的失败原因、取消原因、调度阻塞原因、出口状态 | 保留任务记录与持续状态；手动提交失败另用 Toast | |
| DT08 | 登录与账号探测详情 | 登录进程、回调、身份提供方与账号健康检查结果 | 用户发起操作结果与持续账号异常分别处理 | |
| DT09 | 权限审批与异步问题 | 工具提供的命令、理由、字段标题、必填项和问题正文 | 审批/问题控件，不转成自动消失的通知 | |
| DT10 | 通知发送载荷 | Telegram/系统通知中的会话名、摘要、完成消息和错误摘要 | 用户配置/运行结果决定内容，静态包装文案见 NT 条目 | |
| DT11 | 插值文案 | 会话名、账号名、文件名、时间、数量、模型、端口等 | 模板可审核，实际值不能枚举或写死 | |

## 覆盖范围和追溯

源码盘点包含操作通知调用、错误构造和兜底、状态/提醒字符串、Vue 模板提醒及现有翻译；服务端章节为可能通过 API 或运行诊断暴露的消息，不承诺每条都显示在客户端。极少数只用于匹配上游错误的短语也保留出处供审核，不能把修改识别标记当作修改显示文案。未读取真实会话、凭据、运行日志或个人通知内容。

同目录 CSV 提供相同编号与全文，适合筛选、批量批注。抽取中间产物位于 output/0218/notification-inventory/，供开发追溯，不作为长期规范。

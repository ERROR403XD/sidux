# CodexApp 0.2 封测版本变迁与重构记录

2026-09-13 已完成封版补查及本轮 UI 追加：项目树操作、即时归组、移除确认和四类现有通知。开发与公开源码各 830 项通过；GitHub 0.2.19 附件已更新，59001 使用最终候选，5900 仍运行此前 d20d9fe 包。本轮未执行生产激活。最新事实见 [[20260913-0012-codexapp-封版漏项补查与0.2.19交接]] 第 9 节；之前的 823/826/828 项记录保留为对应阶段。

此页将历史记录收敛为维护者可使用的版本地图，以 0.2.19 封测实现为终点。它记录开发能力的演进，不把每个本地版本号都认定为已经公开发布；早期上游/分支存在混合版本号，不能按所有 Git 标签简单串成线性发布史。公开发布、prepare 和本机激活是三个不同事实。

## 1. 演进主线

早期版本建立浏览器会话、项目、模型、工具和开发辅助；0.1 后期增加本地账号与可靠发布；0.2 前半建立 API、持久投递、自动化和长任务；0.2 后半集中在多账号隔离、额度与激活、界面精简和长期恢复。本轮将 0.2 保留为可长期使用的维护基线，0.3 项目主导 UI 独立规划。

## 2. 0.2.19 最终系统审阅结账

| 审阅项 | 封测结论 | 实际改动与保留边界 |
| --- | --- | --- |
| SCH-01 激活漏出交接门禁 | 已改 | 发布专用 drain/activity 覆盖迟到准备与清理；失败解除冻结；unknown/unsupported 不当空闲 |
| SCH-02 inspect 阻塞控制队列 | 已改 | 慢检查移到短串行区外，有界、同 run 合并，回写核对 revision/通知版本 |
| SCH-03 准备等待与取消 | 已改，保留真实所有权边界 | 90 秒准备期限贯穿 adapter；独占 worker 确认退出后释放，共享不可取消操作仍等真实返回 |
| SCH-04 额度续跑扫描饥饿 | 已改 | 有界轮转扫描，避免长期只检查列表头部 |
| REL-01 依赖/最低运行环境 | 部分改 | 固定已验证的直接依赖版本，prepare 锁文件及 npm ci/PTY 复装验证；未宣称 Node 18 全覆盖 |
| RED 冗余路径 | 有限清理 | 删除确认无业务引用的旧 accountActivationSession；仍有调用的 provider/bridge 路径保留 |
| DATA-01 长期历史与防重 | 已改 | 分段归档、双份永久事实、pending 恢复、派生索引、旧格式兼容与离线导出；不删除防重事实 |
| PERF-01 重复读取/缓存 | 部分改 | 修复具体的项目缓存覆盖与迟到失效；保留必要 initial/ready 同步，不开展全局缓存重写 |
| MOD-01 大模块 | 有限提取 | 抽出本轮需要的准备、组织、暂留、问题与显示职责；App/bridge 等全局拆分留待明确需求 |
| SEC-01 同源主动预览 | 明确保留 | 实测简单 sandbox 破坏模块/相对资源/编辑，按功能优先授权不加破坏性 CSP；0.3 扩大预览前重新设计来源边界 |

“保留”是基于当前使用方式和功能优先的明确决定，不表示相应风险已修复。共享不可取消的操作占位是保护现有任务；提前释放会破坏账号/会话阻塞语义。长期稳定的目标是减少以后反复拆改，不是仅减少本轮改动行数。

## 5. 退役入口与兼容约束

内置 Cloudflare 隧道、旧 Composio 专用 UI、GitHub 技能自动推送及旧完整连接器目录已从当前产品路线退出；原生插件/技能/MCP 与现有提供方适配仍保留。任何进一步删除都先检查实际调用与公开入口。

0.2.19 不改自动化热状态格式和核心账号流程。新增历史格式具备旧源兼容，但旧二进制不会自动识别全部新事实；回退前必须用新包离线 `automation-history --home <目标实例目录> --export-legacy`。不能只换旧程序而忽略防重数据。

## 6. 版本与证据定位

原封测包基线为 df6a5cb97c32；四项修复后的固定包来源为 0612357254c4，后续 74e9321 只扩展组合测试，之后文档更新不改变固定包。最终 prepare 目录、59001、生产保留、测试数量及未验证范围集中维护在 [[20260913-0008-codexapp-0.2封测验收与运行维护]]，避免不同文档各自维护易过期的 PID 或运行路径。

本页不承诺未来绝不维护 0.2。维护准则是：明确故障、局部修复、证据证明核心链不退步；无法证明时撤回。0.3 采用项目主导 UI，但不能把 0.2 的账号、API、调度和恢复契约当成可随布局一起重写的附属功能。

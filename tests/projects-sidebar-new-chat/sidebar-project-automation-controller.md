# 0.2.22：侧栏项目与自动化完整控制器

## 前置条件

- 人工验收使用包含本批代码的59001候选；替换前按仓库规范确认空闲并保留标准测试卷。生产5900不作为测试入口。
- 内部自动化使用权威源码4173和独立合成fixture，脚本为`docs/baseline/022/sidebar-automation-20261012/verify-ui.cjs`。它拦截自动化运行及所选账号模型响应，不执行真实任务。
- 准备两个独立测试账号、物理项目和组织项目。真实手动创建任务时先选择PAUSED，使用唯一名称；记录创建后服务端返回的id，不能假设请求中的新id会被原样采用。

## 菜单、主题与焦点

1. 在1440×1000、768×1024、375×812分别检查浅色中文和深色英文；手机先展开侧边栏。
2. 点击项目三点菜单，检查动作、配色和横向边界；Tab进入菜单，点击菜单外部应关闭。
3. 将窗口高度缩至460并滚动到菜单按钮，菜单应向上打开；恢复原尺寸后再次打开。
4. 分别进入自动化、编辑项目和项目移除确认，取消弹窗；焦点应返回仍连接的项目菜单按钮，菜单/弹窗不残留。

## 草稿、账号与持久化

1. 添加任务，填写唯一名称/提示词及合法时间。选择账号A，再选B；模型菜单只显示B的目录。
2. 保存时取消/关闭/运行按钮禁用；Esc不能关闭忙碌弹窗；同一保存仅发一个PUT，保存后切为编辑模式。
3. 同账号保存或修改status不重新请求模型目录；从A切B各读一次，关闭重开/刷新后的目录仍重新读取。
4. 刷新页面，项目任务徽标和编辑字段保持。模型目录慢/失败时禁止使用旧目录保存，错误可见并可重选账号重试。
5. 用内部合成请求失败脚本检查保存500：编辑器保留，busy解除，操作错误可见；修正后可再次保存。

## 移除、运行与并发

1. 点击任务移除，再取消确认：DELETE数为0；再次确认只删除选定id，其他定义保留。
2. 在允许执行的独立任务上点击Run now：只提交一次对应目标和requestId；busy期间保存、重复运行和同目标项目移除不能穿插。
3. 物理项目有任务时，移除项目先确认；成功后移除对应项目任务。组织项目移除仅取消分组，任务定义和身份继续存在。
4. 运行`pnpm exec vitest run src/composables/sidebarAutomationComposition.test.ts`，覆盖旧读取/外部快照、迟到写入、项目目标回滚、重复请求、账号同步失效及卸载。
5. 项目删除失败并且刷新失败时，只恢复被移除项目；其他项目期间新增/更新的状态保留。卸载后迟到结果不能通知、刷新、重开编辑器或写回列表。

## 清理与回滚

- 仅删除本轮创建的测试id；保留原任务、账号、认证、会话、工作区及两个59001标准卷。
- `verify-http.cjs`只对隔离fixture创建PAUSED定义并按实际id清理；结束时自动化active/queued应为0。
- 4173保留作复验，禁止停用5173或操作生产；候选回滚另行检查空闲并切回已验证代码镜像，不复制运行状态。

## 0.2.22-dev.2：项目与会话自动化标记样式

前置条件：使用包含修复的59001候选，或权威源码4173的独立合成fixture；准备项目及会话自动化数量为0、1、3、12的状态。手工创建的定义全部设为PAUSED，记录实际id。自动化回归脚本和截图见`docs/plans/evidence/022-sidebar-badges-20261014/`。

1. 在375×812、768×1024、1440×1000分别切换浅色与深色主题；手机先展开侧栏。
2. 检查项目行和会话行：数量0不显示标记，数量1只显示闪电，数量3及12在闪电右侧显示数字。
3. 检查长项目名及长会话标题：标题正常截断，标记保持完整，不挤出菜单/编辑按钮；单个标记高16px、图标12×12px、数字10px，各行高28px，不因数量增加而竖排或增高。
4. 收起及展开项目，再刷新页面；标记、数量、配色和圆角保持一致，浅色为浅琥珀色，深色为深琥珀色圆角标记。
5. 会话上已有目标、额度续跑或定时续跑标记时，检查它们仍使用同样的紧凑布局；不必创建或执行实际任务。

预期：项目与会话行共用相同的标记基础样式，所有尺寸下闪电和数字横排居中，无方框、换行或行高变化。纯样式修复不新增请求、监听器或自动化运行。

清理/回滚：只删除本轮创建且已记录id的PAUSED测试定义；恢复主题及项目展开状态，保留59001标准卷。源码回滚时将共享标记规则及会话组件的原作用域规则成对恢复，不能只删除共享规则。

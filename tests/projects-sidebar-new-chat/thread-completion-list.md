## 0.2.22：绿点与项目一键已读

准备：同一项目有普通完成蓝点、自动化/外部 POST 完成绿点、额度黄点、异常红点；至少一个完成会话位于尚未加载的分页。用隔离合成数据验证，浅深主题均覆盖。

操作：
1. 在“未读”筛选中检查蓝点会话显示，绿点会话不因完成进入未读；普通定时续跑完成仍为蓝点。
2. 右键绿点会话，点击“标为已读”：绿点消失；对黄点、红点使用同一动作，问题指示保留。
3. 右键项目，点击“全部标为已读”：蓝点和绿点全部消失，包括隐藏分页的会话；黄点、红点保留。
4. 刷新和在第二个浏览器读取：已确认的完成标记不恢复，问题指示仍在。
5. 在批量已读读取 metadata 时让一个会话完成新回合；旧 token 的确认不能消除新完成。模拟 metadata 连接失败，不能报告部分成功；明确已删除的会话不会阻塞其他确认。

预期：绿点只是可确认的完成状态，不计未读。已读接口仅修改完成列表，不操作额度、回合或中断列表；只有单独的忽略问题操作可处理黄红点。

性能：只读取已有完成标记的 metadata，不读历史全文；并发上限 4，一次原子保存。12 个合成标记的单测确认最大并发 4、确认一次；元数据失败则不写入。没有完成标记时无会话读取，无新轮询。

# 侧栏会话与项目右键菜单定位（0.2.22-dev.4）

## 前置

4173 当前源码验证服务，侧栏至少一个项目和两个会话；数据使用独立测试 home。浅深主题，1440×1000、768×1024、375×812。自动化：`node scripts/verify-022-sidebar-context-menu.cjs`。

## 操作与预期

1. 在会话标题左端右键：菜单从点击位置附近打开，不锚定行尾省略号。换一个横坐标再次右键，菜单跟随新位置。
2. 对项目标题重复操作；会话和项目菜单只能显示一个。
3. 在窄窗口右侧、靠近底部右键：菜单自动限制在视口内，长菜单可滚动。
4. 指针从行移动到菜单：菜单不因离开标题而消失。点击空白处关闭。
5. 点击会话或项目的省略号按钮：保留按钮右对齐定位。项目菜单 Escape 关闭并恢复焦点。
6. 明暗主题分别检查背景、文字、菜单按钮；小屏展开侧栏后重复。

## 性能与清理

定位只读取当前菜单及锚点尺寸；项目菜单复用 AppPopover 的尺寸观察、滚动/窗口监听及清理。没有新增网络请求、定时轮询或遍历所有会话。原有项目 Git 状态读取保留。

关闭测试上下文，不修改或删除真实项目/会话。源码回退本修复提交即可，持久数据无迁移。

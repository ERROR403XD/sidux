### 0.1.89：通过项目 AGENTS.md 声明关联目录

前提：选择一个主项目目录和实际可见的关联目录；59001 仅共享 `/home/Code`。本轮专用示例位于 `/home/Code/codexapp/output/ui-0.1.89/related-project/AGENTS.md`，关联 `../related-tools`。这是手工维护项目说明的约定，没有 WebUI 编辑入口或多根文件树。

操作：
1. 检查主目录 `AGENTS.md` 是否为符号链接，检查 `AGENTS.override.md` 及父目录有效说明；不要沿指向项目外或全局文件的链接写入，不改 override。
2. 保存原内容并记录修改时间，只新增/更新 `<!-- codexapp:related-directories:start -->` 至 `<!-- codexapp:related-directories:end -->` 之间的区块。列出主目录、关联目录、用途及跨目录规则。重复/缺失标记或文件已发生变化时停止覆盖，先人工解决冲突。
3. 在候选环境选择主目录创建新会话，请 AI 说明主 cwd、读取关联目录 README，并返回其中唯一标记。真实账号激活后由用户执行此步。
4. 旧线程明确要求重新读取主目录 AGENTS.md；不假定自动刷新。检查文件树、终端及 Git 仍以主目录为默认。
5. 删除一条关联说明，确认仅说明变更，目录、文件、线程都保留。检查全局 AGENTS.md 及符号链接目标未改变。

预期：新会话按项目说明按需访问关联目录；关联目录自己的指令需另行读取；声明不赋予权限、不新增挂载。既有说明保留，重复维护不追加重复区块。不得把上述 fixture 文件操作验证当成模型指令加载成功。

回滚：仅恢复本轮专用区块，保留用户后续修改；新建文件只有仍完全由本轮内容组成时才可删除。本轮示例保留供用户验收，不自动清理其他项目。

性能：纯项目说明约定，无额外 API、全目录扫描、项目数据迁移或全局指令写入。

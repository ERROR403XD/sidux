# 查看会话只读加载（0.2.22）

准备：空闲的隔离 4173 或 59001 候选；同一项目至少三个已有会话。打开网络记录，覆盖浅色和深色。

操作：
1. 记录项目会话顺序和会话 updatedAt，点击中间会话，等待最近历史加载。
2. 切换到其他会话，再回到原会话；刷新页面。
3. 检查网络和服务端 RPC：查看仅允许 thread/read 和历史分页，不能调用 thread/resume、turn/start，也不能更新时间或移动到顶部。
4. 实际发送一句消息：此时才允许恢复执行；新回合开始、完成及列表更新正常。
5. 若连接在另一个浏览器中改变，首次发送应按恢复返回的真实来源重新计算模型和推理强度；后续历史读取不能覆盖已绑定的来源。
6. 延迟历史或发送响应，进行账号切换、停止/重新连接、快速切换会话，确认旧响应不会覆盖新会话、解除新请求的 loading 或自动发送。

预期：查看不激活执行、不改变排序；发送时仍可正常恢复。只读失败显示原错误，不自动用恢复动作兜底。

性能：首页无恢复请求，会话查看至多一次历史读取，保留缓存和请求合并。真实云端延迟另行观察。

清理：关闭验证页，取消合成回合；不删除候选或生产会话。回退对应代码提交，不清空持久状态。

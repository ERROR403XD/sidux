### 0.1.89：中文适配和语言切换

前提：候选 59001；准备带提交历史的测试 Git 项目、测试线程及自动化。浅色和深色主题均执行。

操作：打开顶部 Git 面板，展开提交文件、搜索分支/提交；检查标题、加载/空状态、复制 tooltip、错误提示。查看侧栏线程/项目菜单、创建目录弹窗、自动化详情和新增弹窗、技能/插件/App/MCP 详情、账户菜单、文件审阅、展开输入框和附件。语言从 English 切为简体中文，再切回；有提示消息时切换，刷新后确认选择持久化。

预期：自有控件、计数、提示即时切换；路径、分支名、提交内容、模型回复、产品名、原始错误详情保留；Git 命令 Commit/Pull/Push/Fetch/Reset/Rebase/Merge/Checkout 保留。不同目录同名项目的 tooltip 显示目录。中文不挤出按钮，无深色页面上的浅色面板。

验证尺寸：1440×900、1366×600、375×812、768×1024；100%/125%/150% 缩放。截图与真实设备检查由手工验收记录，不将单测视为视觉验证。

清理：恢复语言、主题和缩放，移除仅用于本轮的测试自动化。

性能：沿用响应式字典，无 DOM 扫描或翻译网络请求；常量菜单保留消息 key，在 render/computed 中翻译，动态提示保留参数后渲染。

# 弹窗视觉统一至持续目标窗口

前提：4173 当前版本；浅色及深色主题，1440×900、375×812、768×1024；只使用虚构线程、自动化和项目草稿。

1. 打开“＋ → 持续目标”，观察背景、16px 圆角、边框、标题区、表单字段与描边操作按钮。
2. 打开自动化编辑，确认与 Goal 相同的窗口外观、右上关闭按钮、独立滚动内容区和固定底部操作区；窄屏可访问全部配置，关闭不保存草稿。
3. 模型、思考强度、计划类型、状态可以正常选择；菜单在模态窗口前方且可点击。普通按钮为描边样式，Remove 为红色文字和边框，不能出现强烈亮红填充或深色页面上的白色表面。
4. 检查重命名、删除会话窗口：输入、Enter 保存、取消、Esc、点击背景与拖选背景保护有效；删除有红色提示，不执行真实删除。
5. 检查项目新建、文件夹选择、项目导出和账号登录回调等现有模态窗口的表面、输入和按钮样式一致；仅打开和取消，不发起真实登录、导出或创建操作。
6. 回归历史弹窗的 100 条分页，以及 Goal 暂停/继续/清除。确认菜单退出后原窗口可继续操作。

实现：自动化、重命名、删除复用 AppDialog；语义为 role=dialog、aria-modal=true 的弹窗使用共用颜色/边框/圆角变量。保留各流程尺寸与布局，不修改侧栏/正文中的普通按钮。

性能：CSS 统一与复用组件不增加 API；打开模型和强度菜单无新增网络请求。清理时只关闭测试窗口、还原虚构配置；保留生产数据。

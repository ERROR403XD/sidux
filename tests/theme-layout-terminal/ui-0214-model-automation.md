# 0.2.14 模型选择器与自动化配色

前提：当前源码 4173，模型目录含 Astra、Sol 及对应推理强度；分别使用浅色、深色主题。

1. 在新会话和已有会话打开模型选择器。收起时显示单行，例如“Astra 中”；模型名过长时省略，强度仍可见。
2. 打开弹层，搜索并切换模型，直接选择推理强度；默认按钮恢复模型默认强度。按 Escape 关闭，刷新后所选模型应保留。
3. 在 1440×900、768×1024、375×812 检查弹层边界、滚动和键盘关闭；页面无横向溢出。
4. 打开自动化，背景、选中行及创建按钮采用黄色系；深色主题仍保持可读。
5. 打开 API 出口；已启用但未建立组件时显示“已启用”，没有“按需启动”。

清理：恢复测试前模型与主题设置；请求桩不写真实用户配置。

证据：`output/0214/ui.json`；`output/playwright/0214-models-*.png` 和 `0214-automation-*.png`。6 组尺寸/主题通过，模型选择刷新持久化通过；200 次重复 MCP 事件合并为最多一次请求。模型弹层只过滤已加载列表，不新增网络请求。

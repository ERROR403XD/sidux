# 0.2.14 模型选择器与自动化配色

前提：当前源码 4173，模型目录含 Astra、Sol 及对应推理强度；分别使用浅色、深色主题。

1. 在新会话和已有会话打开模型选择器。收起时显示单行，例如“Astra 中”；模型名过长时省略，强度仍可见。
2. 打开弹层，搜索并切换模型，直接选择推理强度；默认按钮恢复模型默认强度。按 Escape 关闭，刷新后所选模型应保留。
3. 在 1440×900、768×1024、375×812 检查弹层边界、滚动和键盘关闭；页面无横向溢出。
4. 打开自动化，背景、选中行及创建按钮采用黄色系；深色主题仍保持可读。
5. 打开 API 出口；已启用但未建立组件时显示“已启用”，没有“按需启动”。

清理：恢复测试前模型与主题设置；请求桩不写真实用户配置。

证据：`output/0214/ui.json`；`output/playwright/0214-models-*.png` 和 `0214-automation-*.png`。6 组尺寸/主题通过，模型选择刷新持久化通过；200 次重复 MCP 事件合并为最多一次请求。模型弹层只过滤已加载列表，不新增网络请求。

## 0.2.15 字体、账号控件与简洁文案

准备：当前 4173 源码或 59001 候选；用虚构账号和暂停任务验证保存。视口为 1440×900、768×1024、375×812，各检查浅色和深色。

操作：

1. 打开对话模型菜单，确认搜索自动聚焦；输入搜索词，检查过滤结果和清空恢复。桌面输入字号 13px；手机/平板沿用 16px 防输入缩放规则。

### 0.2.15 浅色入口、发送框与自动化控件

前置：当前源码的 4173、独立账号与自动化 fixture；1440×900、768×1024、375×812，分别使用浅色/深色主题。
1. 查看左上 API 出口入口，未悬停时也有蓝色背景和边框。
2. 逐个悬停发送框附件、技能、模型、Fast、麦克风控件；字号均为 13px，高度 32px，圆角与悬停底色一致。下拉 V 标识不显示，菜单点击、键盘操作正常。
3. 新建自动化，切换“已有聊天”“项目”；文字与背景有清晰对比，选中状态可辨认。
4. 编辑自动化，模型、思考强度、快速模式在同一行；勾选快速模式，保存、关闭、刷新后再打开，开关仍勾选且 serviceTier=priority。无已知 Fast 能力时禁用；模型默认仅提供 Fast 时不能错误地关闭。
5. 在手机上核对控件没有超出视口，弹窗内容可滚动；保存成功提示约 3.5 秒后消失。
清理：关闭弹窗和手机侧栏；自动化写入与执行使用请求拦截，不修改真实计划或账号。

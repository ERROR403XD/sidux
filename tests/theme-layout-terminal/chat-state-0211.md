# 0.2.11 消息与侧栏状态一致性

前置：隔离候选 59001，至少两个会话，其中一个执行持续任务；准备带图片/文件的消息和异步问题卡片。

1. 任务运行时发送引导；另将已排队的消息点“引导”。投递确认后立即出现用户消息，任务继续执行；下一次同步、完成后刷新均只有一条。
2. 连续发送相同内容，确保两个真实输入都保留；测试同轮次引导和跨轮次输入。附件完整，不因文本相同而被删除。
3. 提交问题回答：卡片只有得到投递确认才显示已回答；未确认显示可核对错误，待发送区域不出现普通编辑/引导/删除操作。重试复用投递身份，不再发送第二份回答。
4. 回复中、刚完成和完成后分别刷新，检查用户内容、助手进度、工具结果与最终回答无重复。包括流式 ID 与历史重建 ID 不同的场景。
5. 后台会话完成时出现蓝点，打开后清除；运行时转圈。重放旧轮次 completed、重复 started 和延迟列表响应，不能覆盖新轮次运行状态。断连后完成再重连，无需手工刷新即可校准。
6. 浅深主题验证真实卡片及队列；使用 TestChat 独立标记检验 Markdown 与文件链接，断线重连测试保存刷新后截图。

回滚：仅撤回状态合并/投递显示代码；保留真实历史、投递凭据和未发送消息。清理仅删除 fixture 会话与截图以外的临时测试数据。

自动回归：新增引导立即显示、队列转引导、用户通知重复、相同文本真实输入、旧轮次通知、延迟列表、合成 ID/正式 ID、问题回答未确认等用例。运行时和截图验收结果另记录在本版报告。

性能检查：历史/实时索引按消息身份合并；每次确认只追加一个本地显示项；队列转引导复用操作返回的回执，不额外获取整段历史。重连复用一次列表刷新及当前会话读取，不逐会话全量读取。乐观项匹配仅在未匹配用户项时执行，已确认消息通过 ID/序号索引。

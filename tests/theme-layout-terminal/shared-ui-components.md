# 共用弹窗、浮层、单选和按钮组件

前提：使用当前 4173 或隔离 59001 候选；虚构自动化/线程；1440×900 浅深主题、375×812 浅深主题、768×1024 深色。关闭现有浮层后开始。

1. 打开“＋ → 持续目标”，确认 AppDialog 表面、AppButton 描边、关闭图标和输入框符合统一风格。Tab 从末尾回到第一个控件，Shift+Tab 反向循环；Esc 关闭并返回打开前焦点。
2. 打开自动化编辑，打开模型单选框。搜索框自动获得焦点，继续输入可筛选；↑↓ 与 Enter 可以选择，不发起自动化运行。取消应保留原选项。
3. 在搜索框有内容时按 Esc：第一次清空搜索，第二次收起浮层，第三次关闭弹窗。前两次不能把后面的弹窗一起关闭；关闭浮层后焦点在原触发按钮。
4. 从提示词内拖动到背景、从背景拖动到窗口，以及右键点击背景，都不能关闭弹窗；完整左键背景点击才关闭。手机端自动化编辑原本会展开侧栏，关闭后可另点抽屉背景回到详情。
5. 保存期间关闭按钮不可用，不能通过 Esc/背景关闭；普通按钮保持描边，Remove/删除为红色描边。确认保存失败信息和原业务处理不变。
6. 展开输入框后打开思考强度，菜单对齐触发点并完整落在视口内；滚动、缩放及选项过滤后仍正确定位。
7. 用 `/model` 与 `/skills` 打开选择框：搜索输入获得焦点，技能支持描述/来源/创建/移除等原功能；键盘选中虚构提示词后仅更新草稿，不自动发送。普通输入框内的斜杠命令选择器仍保留不抢焦点的原交互。
8. 回归历史预览 5 条、全部历史每页 100 条、分页后滚动归零，以及重命名 Enter 保存/删除取消。

性能验收：浮层关闭时没有自身全局 pointerdown/resize/scroll 监听；一次打开新增 3 个，关闭移除 3 个。布局事件使用 RAF 合并，ResizeObserver 和 RAF 在关闭/卸载时释放；开关选择框无新增 API。记录构建体积和一次有效线程加载的请求数量。

清理：关闭弹窗、收起输入框，还原虚构配置；不删除真实线程、不运行实际自动化、不改生产认证或 5900。视觉和接口约定见项目的 UI 组件规范。

### 0.1.90：触摸选择与 Teleport 归属

- 前置：4173 隔离环境；深浅主题；手机、Pad 横竖屏和桌面；启用触摸模拟或真实 Pad。
- 操作：从侧栏设置将语言切为简体中文，再切回 English，刷新后检查；依次操作模型、思考强度、自动化模型/强度，以及包含子选择框的菜单；展开输入框后再次选择思考强度。
- 预期：点击 Teleport 浮层中的选项时，所属父面板保持打开且选中值更新；刷新后语言仍保留；点击无关区域正常关闭，Escape 正常退出；展开输入框后的浮层仍对齐触发器且不超出视口。
- 视觉：深色侧栏中的语言、Provider、听写语言触发按钮，以及审查面板的分支选择，使用共用输入表面、文字和边框色，不能残留白底灰字。浅色下文字和边框同样可读。
- 性能约束：浮层归属使用 WeakMap，只沿事件路径和所属触发器查找，不扫描整个 DOM；关闭/卸载清理事件监听和 ResizeObserver，不新增网络请求。
- 清理：恢复原语言和主题；关闭夹具页面。

### 进入 0.2 前：WebKit 尺寸监听与低高度菜单

前置：当前 4173 或隔离 59001，Chromium 与 WebKit，浅/深主题；375×812、820×1180、1024×768，并加入 800×480 低高度视口。

1. 重复刷新内部线程、缩放视口、展开/收起输入框，再切换自动化页面。预期页面标题、侧栏与输入框位置稳定，交互阶段没有 ResizeObserver loop 告警。
2. 打开 Git 分支菜单，选择分支和包含多个文件的提交。预期菜单全部位于视口内，内部滚动可到达最后一项，分支/提交/文件均可读；不得实际 checkout 或 reset 测试仓库。
   Reset 使用共用 AppButton 的红色描边风格，浅色/深色均与窗口按钮一致；深色时不能出现旧版的整块白色填充。
3. 打开模型、强度和语言菜单，验证触摸选中、Esc、关闭后焦点及深浅主题；离开页面后没有残留测量 RAF 或观察对象。

性能：ResizeObserver 通知只安排下一帧测量，同帧合并侧栏目标；标题高度变化小于 0.5px 时不改 CSS。无新增 API 请求。清理：关闭测试窗口、恢复视口，保留真实线程及 Git 状态。

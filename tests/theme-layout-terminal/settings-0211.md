# 0.2.11 设置与账号区域

前置：使用独立 CODEX_HOME 的候选，准备两个测试账号及一个有草稿的会话；同时覆盖无账号和无用量状态。

1. 在侧栏展开、折叠及移动端检查工具条顺序：侧栏、主题、设置、搜索、新建。
2. 打开设置，检查账号与连接、通用、外观、输入与发送、集成、关于；逐项修改旧偏好并刷新，确认原保存语义和配置保留，返回会话草稿不丢失。
3. 循环主题，检查深色、浅色、系统图标及系统变化；两处设置保持一致。
4. 左下角上下文和账号用量独立显示；打开账号弹层，检查长名称、当前标识、双窗口额度、更多菜单、双版本；刷新列表不重载会话。测试添加、重新认证、刷新额度、切换限制和移除确认。
5. 检查“关于”版本与实际运行产物一致，能力文案没有“尚未接入”的旧说明；失败状态可见，重复打开不重复检测。

视口：1440×900、375×812、768×1024，全部浅/深主题；保存实际弹层和设置页截图。关闭子菜单后焦点正确，登录对话框不被父菜单的 Esc 提前关闭。

回滚/清理：恢复测试偏好；只移除本轮新增的测试账号（不可移除激活账号），不清空已有账号/会话数据。组件回滚不修改运行凭据。

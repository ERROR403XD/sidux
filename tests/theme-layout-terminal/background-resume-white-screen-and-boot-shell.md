# 后台返回白屏与冷启动首屏外壳

前置：使用当前源码构建的本地服务（验证环境 `127.0.0.1:4173`，`CODEX_HOME` 指向隔离目录，不干扰 59001）。准备慢速网络模拟（把 `/src/`、`node_modules`、`.css`、`.js` 请求延迟约 2500ms）和浏览器上下文级 `localStorage` 预设。

1. 冷启动首屏：在 375×812、768×1024、1024×768 三个视口分别以浅色和深色偏好冷启动，资源请求保持 2500ms 延迟。
   预期：首帧即为不透明主题底色（浅色白、深色近黑），不出现透明 `html/body` 或空白 `#app`；约 300ms 后出现 spinner 和“正在加载界面…”；应用挂载后加载层被移除，控制台无 error、无 pageerror。
2. 启动失败分支：阻断主模块（例如让动态 import 失败），等待超过 15 秒。
   预期：加载层被移除，显示“界面加载失败”恢复面板，面板主题跟随当前深浅色，按钮为“重新加载/稍后”。
3. 主题引导：分别预设 `codex-web-local.dark-mode.v1` 为 `light`、`dark`、`system`。
   预期：早于主模块执行的引导脚本按预设设置 `html.dark`，并把 `meta[name=theme-color]` 同步为 `#ffffff` 或 `#09090b`，首帧无浅→深闪烁。
4. 应用内切换主题：加载完成后在设置中依次切换 浅色→跟随系统→深色→浅色。
   预期：`html.dark` 与 `meta[name=theme-color]` 一起更新，加载层不会重现，无残留遮罩。
5. 后台返回：用移动视口打开会话，切入后台使页面隐式冻结，再回到前台。
   预期：返回前台后内容可见并自动刷新，不出现长时间白屏等待；若应用未恢复，剩余兜底是第 2 步的恢复面板，而不是纯空白。

结果判断只覆盖首屏外壳与主题，不代表模型、历史或外部服务可用。性能：加载层为纯静态 HTML/CSS，不新增请求、定时器或轮询，`prefers-reduced-motion` 下禁用动画。清理：关闭临时浏览器上下文与慢速路由拦截；保留既有 4173 服务，停止自己新建的其他验证进程。

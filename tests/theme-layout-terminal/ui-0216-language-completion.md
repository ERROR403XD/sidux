### 0.2.16：中文界面英文补全

前提：59001 隔离候选；使用测试账号、测试项目和测试自动化。不要在真实账号消耗重置机会。准备名称为“保存”的项目、中文线程和中文自动化提示词，验证用户内容不会被翻译。

操作：
1. 在设置中由简体中文切换 English，不刷新，检查账号、额度日期、定时激活、默认模型/推理强度、通知设置与关于区域。刷新确认 English 保留，再切回中文。
2. 打开账号设置、登录和重置机会说明；展开通知规则，检查占位符说明仍显示完整的 `{{account}}`、`{{message}}`。保存的通知内容保持原文。
3. 检查 API Proxy、自动化列表/详情/执行历史、插件与 MCP、斜杠命令、Goal、任务搜索和后台终端；让测试接口返回中文错误，检查英文提示及打开期间切换语言。
4. 项目右键菜单选择 Edit project，检查 Additional working directories；空文本框显示两行 `/home/Code/project1` 和 `/home/Code/project2`，实际值为空。中文项目名“保存”仍显示“保存”。中文时菜单为“编辑项目”，字段为“附加工作目录”。
5. 检查模型推理滑块、主题 tooltip、额度 Today/Tomorrow/星期；日期保持所选时区。检查聊天正文、终端输出、插件描述、路径、用户提示词未被转换。
6. 浅色/深色检查桌面 1440×1000，移动 375×812，平板 768×1024；检查弹窗和设置表单没有横向溢出或深色下浅色面板。

预期：应用自有中文文案有对应英文；语言切换即刻更新，刷新保持偏好；状态/错误中的路径、ID、数值保留。加载失败恢复面板与界面语言一致。外部/用户内容不属于界面词典，不自动翻译。

清理：恢复原语言及主题；关闭测试弹窗，删除测试记录。浏览器测试通过请求拦截验证保存/通知，不实际发送通知或使用重置机会。

性能：字典查找与预编译模板匹配；不扫描 DOM，不增加翻译请求。检查首屏 profiler 的线程列表/技能/模型请求数、总响应大小和 warnings；记录构建体积，不将模拟数据检查称为真实模型执行验证。

英文命令搜索：输入 `/discuss`，预期显示 `/plan` 及英文说明；中文模式仍可用 `/计划` 搜索。自定义技能描述即使为“保存”，也保持该原文。

### 0.2.16 术语统一复核

前提：使用隔离候选和测试账号；通知接口使用拦截或测试服务，不发送真实通知，不消耗重置机会。

操作：中文设置检查“默认推理强度”“会话宽度”；账号设置检查“5小时额度重置通知”“主额度重置通知”，开启测试规则后检查新模板含“已重置”。切换 English，检查 reasoning effort、conversation、quota reset、banked resets。打开会话菜单，检查“额度重置后继续 / Resume when quota resets”及重命名、删除会话。刷新确认语言保存。依次验证 1440×1000 浅色/深色、375×812 浅色、768×1024 深色。

预期：普通会话不再标为线程；内部 thread ID、thread/tokenUsage/updated 和单回合 turn 保留技术含义。“恢复凭据”“恢复默认速度”“恢复子任务”不被误替换为重置；购买 credits 单独为点数。将项目名或变量值设为“线程聊天额度恢复”，显示与插值仍保留原文。旧自定义通知不自动迁移。新代码遵循《中英文术语约定》。

清理：关闭测试菜单、恢复原语言，保留用户自定义通知模板；删除仅用于测试的浏览器数据。性能检查字典查找和模板匹配不新增 API 调用。

### 账号额度标签布局

- 前置条件：账号额度包含 300 分钟与 43200 分钟窗口；可使用请求拦截样本，不消耗真实额度。
- 操作：中英文分别打开设置页账号卡片，在 1440、768、375px 宽度与深浅主题下查看标签、进度条、百分比及重置时间。
- 预期：`30-day quota` / `30天额度` 保持单行，标签不重叠进度条，额度行无横向溢出；标签列按内容宽度分配，进度条自动缩短。
- 清理：关闭测试浏览器上下文，移除请求拦截；无需修改真实账号数据。

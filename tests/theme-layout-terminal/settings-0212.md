# 0.2.12 设置、API Key 与账号界面

前置：隔离候选 59001；至少一把可用 Key、一把撤销 Key；模拟或测试账号。使用 1440×900、768×1024、375×812，分别检查浅色和深色。

1. 打开 API 出口：模块按钮按“创建 key → 查看已失效API Key → 保存配置”从左到右同排排列，手机宽度也保持按钮同排。只显示启用且未过期、未撤销的 Key。点“查看已失效API Key”才显示撤销、停用、过期记录，可返回生效列表。
2. 修改 Key 行内账号和“受保护”：保存前无请求；点模块“保存配置”后保存修改的策略，刷新后保持。多条保存中途失败时已成功条目保持，未成功草稿仍可重试。
3. 检查名称、尾号、到期同行，最近使用次行；Token 统计默认折叠。完整 Key/统计起始等指定提示不出现。
4. 创建 Key：复选框与“受保护”垂直居中；账号下拉菜单和搜索框共用宽度，长账号可完整选择，弹层不超出视口。取消，不创建真实 Key。
5. 在设置中打开账号“⋯”：每个按钮在面板内留出边距。Free 的长期额度使用零补齐 MM/DD；七天以内显示周几，今天、明天、后天优先显示。
6. 切换技能、自动化、API 出口、设置：主标题无图标，页面宽度统一为最大 1100px，24px 内边距（手机12px），使用统一表面、边框和圆角。
7. 会话 Fast 开启：闪电为黄色且发光，整个按钮有黄色发光描边；关闭后恢复原样。浅深主题均检查。
8. 打开一个旧会话使其已读，随后过滤或分页使该会话离开当前列表，刷新并重新找到：不得仅因列表裁剪丢失已读记录而出现蓝点。

清理：恢复测试 Key 策略，删除合成数据；恢复 Fast。撤销真实 Key 不可逆，只在隔离数据中测试。

自动证据：`output/0212/ui.cjs`、`ui.json`、`output/playwright/0212-*.png`。请求拦截模拟账号与模型，无真实额度消耗。

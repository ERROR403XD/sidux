# 0.2.17 目标与设置

前提：独立 59001 候选，测试账号/本地模拟服务；中英文、浅深主题，1440×1000、768×1024、375×812。

1. 打开 `/goal`：仅保留目标、模型、推理强度、预算和操作；指定三段说明及“预算与暂停说明”已删除。输入 `100`、`2k`、`30M`、`0.4B` 后读取保存结果，预算分别为 100、2000、30000000、400000000；留空为 null。刷新后值不改变。
2. 观察正在推理的会话：中英文显示“思考中”/Thinking；模型设置继续显示“推理强度”/Reasoning effort，刷新前后语义一致。
3. 侧栏左上角“应用 / 插件 / 技能 / MCP”入口使用绿色闪电图标，浅深色均有绿色背景和边框；点击打开目录；集成中不再有重复入口。
4. 设置内 POST、Telegram 平级显示；分别有保存和测试按钮；POST 免打扰在按钮下方；Telegram 不折叠，用户 ID 占位符第三行为 `*`，没有冗长授权说明。
5. 所有适合布尔选择的控件使用开关，检查键盘 Space、禁用状态和深浅主题；测试通知仅拦截请求或发送到本地模拟服务。

6. OpenAI 账号设置：未设置别名时输入框为空且没有 placeholder，不显示“留空使用原名称。”；保护文案为“保护值范围内的主额度仅限受保护任务使用”，英文同步。
7. API key 页切换“查看失效 API key”与“返回生效 API key”：空格/大小写一致，中文按钮宽度不变化。
8. 将主题切到跟随系统：显示 Lucide SunMoon，尺寸 16px、描边 1.7，与相邻图标一致；切换系统配色时页面跟随改变，手动浅/深色仍显示原有太阳/月亮。

9. 账号卡片及侧栏摘要同时有 5 小时和 7 天/30 天窗口时，5h 在上；中文显示 5小时限额、7天限额/30天限额，英文显示 5h limit、7-days limit/30-days limit。1440×1000、375×812、768×1024 检查标签不换行、不与进度条重叠，数值和重置时间正确。设置页和账号弹出区各自的全部 OpenAI 卡片共用列宽，跨卡片进度条起点、终点一致，列间距 7px；以 5 小时/7 天、5 小时/30 天、1%/100%、短时间/长日期混合验证。切换语言、更新额度或移除最长标签所在账号后仍自动对齐。左下角默认账号摘要独立计算列宽，不受其他卡片影响。

10. 设置 → 外观：“主题”/“Theme”和会话宽度使用 AppSelect 下拉框；点击选项直接生效，点击行标签不循环切换。选择自动/浅色/深色，以及标准/宽/超宽，验证页面主题、会话宽度 CSS 变量和刷新后的选中值。中英文、明暗主题和三种宽度下菜单宽度与触发框一致、不越界、不出现原生 select；调整窗口时展开菜单同步调整宽度。主题和会话宽度只更新本地偏好，不产生设置写请求。

11. 设置 → 集成 → Telegram：标题下显示“启用Telegram通知”/“Enable Telegram notifications”，与 POST 使用同一开关组件。使用拦截的测试凭据开关并保存，刷新后保持选择，Bot token、授权 ID 和已有会话绑定不丢失；旧配置默认保持启用，无配置默认关闭。关闭时测试按钮禁用，后端拒绝测试请求，自动回合通知和上线提示不发送、不读取会话历史；显式机器人命令仍可回复。开启后测试按钮先保存当前设置，再发送测试请求；每次点击各产生一次请求。模拟读取历史/分段发送期间关闭，剩余通知不得继续发送。全部网络使用模拟服务，不发送真实通知。

12. 定时激活：启用开关单独一行，生效账号与每日激活时间并列对齐；添加时间右边缘与 OpenAI 添加账号一致。主区不常驻显示历史跳过原因，右下角打开“激活记录”。准备同一天两个时刻及前一天一个时刻的样本，每页对应一次计划、同次多个账号并列列出；翻页/选择时刻可访问所有保留记录，空记录和加载失败可读。使用虚构时钟验证最近三个日历月、月末截断、旧记录迁移、服务中断后结果不重复；不得用真实账号发送激活测试。

13. Telegram 免打扰：与 POST 的开关、起止时间输入一致，按全局时区判断；更改后刷新保留。桌面两张卡的标题、启用、字段、按钮、免打扰开关对齐，单侧展开时间仍对齐；窄屏上下排列。模拟跨午夜免打扰，自动通知暂存、服务重启后仍保留，到结束时只发送一次；关闭通知清空待发送记录，更换机器人后旧记录不得发给新机器人；显式测试通知与 POST 一样不受免打扰时段限制。使用模拟请求，不能向真实接收人发送。

14. WebUI Logo/标题：分别上传 SVG、PNG、ICO，验证设置预览、favicon、Apple 图标、网页应用 manifest 的 192/512 图标及 maskable 图标、Windows browserconfig、登录页图标；刷新仍使用新图。固定标题不随会话变化；前缀模式显示“自定义标题 - 会话标题”，无会话只显示自定义标题。含 `<`、`&`、`$&` 的标题显示为文字；移除 Logo 恢复默认，空标题恢复默认命名。浏览器自动化验证只操作 4173 测试状态，并恢复测试前配置；已有桌面快捷方式由系统控制图标缓存，实际系统更新速度另行人工确认。

清理：删除本次创建的测试目标/样本设置，恢复测试前设置；不得触碰生产账号、真实重置机会或真实通知接收人。

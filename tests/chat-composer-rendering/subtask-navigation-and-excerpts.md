# 0.2.5 子任务导航和任务摘录

前提：当前源码或 59001 候选，CLI 0.153.4；使用隔离会话与已知内容，不操作生产或当前开发 Goal。子任务实时状态可用原生 schema 的受控夹具；不为此额外生成子代理。

1. 打开含 collabAgentToolCall、subAgentActivity 的会话。折叠时显示动作、目标身份和原生子任务状态；调用完成而子任务 running 时仍显示运行中。展开查看有界指令和输出摘要。
2. 先到 completed，再到同 ID 的旧 inProgress；状态不倒退。刷新后历史与实时一致；缺失目标只显示不可用，不猜测关系。
3. 未展开子任务时检查无 parentThreadId 列表请求。展开每页 20 个直属子任务；父 ID 不符的数据不可显示。失败后保留入口可刷新；更多页不重复，最多显示 200 个。
4. 主任务输入草稿，打开子任务，再刷新。名称/角色、上级入口仍正确；原生 canAcceptDirectInput=false 时不能直接发送。返回上级恢复原草稿；打开不存在的任务后仍能返回原会话。
5. 打开“搜索任务”或 `/tasks`。默认最近任务；切换标题/正文，快速改变查询，旧响应不能覆盖新结果。查询失败可重试，分页保留已有结果并检测重复游标。
6. 选任务前不读取历史。点击“插入任务摘录”后只读取该任务最近 10 回合，最多 6,000 字符，工具输出和 commentary 不进入摘录；截取时有说明。关闭窗口或切换会话中断等待，不能插入到另一个草稿。
7. 摘录追加到现有草稿，刷新、排队和编辑后仍保留。真实内部会话发送后，模型能够从显式摘录读取测试事实；不把 thread:// mention 接收视为内容已加载。
8. TestChat 发送唯一 marker、任务内部链接及 `/tmp/fixture.md:12` 文件链接，断言 href/title/text 均正确。任务链接指向当前实例，文件链接仍按既有浏览入口呈现。
9. 在 1440×900、375×812、768×1024 浅深主题重复检查面板、任务窗口和真实消息，无横向溢出、浅色浮层或重复 live overlay。保留完整 URL、视口、断言和截图路径。

清理：删除浏览器测试草稿，停止本版独立认证容器并保留必要测试卷。回退前核验共同空闲；只回退应用镜像，不还原用户状态。

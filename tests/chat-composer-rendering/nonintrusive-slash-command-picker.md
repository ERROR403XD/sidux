# 0.1.90：斜杠命令选择器

前提：4173 使用隔离的 `CODEX_HOME`，或在 59001 内部测试会话操作。至少准备一个虚构技能和一个保存的提示词。不要向真实业务会话发送测试文本。

1. 在空输入框、空白后、换行后输入 `/`。预期浮窗靠近输入框，焦点仍在 textarea，显示命令名、描述和类别；默认没有选中项。
2. 连续输入英文名称或中文描述。预期本地过滤，没有按键触发的 HTTP 请求。每次修改查询均清除键盘选择。
3. 第一次按 ↓ 选中第一项，↑ 选中最后一项；继续按键循环选择。按 Enter 仅执行已选项；鼠标点击也能执行，但悬停不会成为键盘选中项。
4. 直接输入 `/plan` 并按平时的发送键，不使用方向键。预期发送原文字；不强制解释为命令。分别验证 Enter 发送和 Ctrl/Cmd+Enter 发送设置，Shift+Enter、Tab 保持原语义。
5. 测试 `/tmp/path`、`https://example.test/a/b`、日期、代码块及正文斜杠。预期不吞字符。粘贴包含斜杠的文本不主动打开窗口。
6. 按 Esc 或点击外部后继续输入当前 token。预期浮窗保持收起、文字保留；离开 token 后输入新的 `/` 可重新打开。执行命令后再次输入 `/` 也能打开。
7. 使用中文输入法组合输入，特别在候选确认时按 Enter。预期不发送消息、不选择命令；组合结束后继续搜索。
8. 选择 `/plan`、`/default` 切换已有模式；选择 `/model`、`/skills` 打开现有选择器。取消子菜单时保留斜杠文本，选择时才替换对应 token。期间改动草稿不得误删新文字。
9. 在 `前文 /prompts:weekly 后文` 中选择保存的提示词，预期只替换命令 token；选择 `/skillname` 附加技能路径，不自动发送，保留已有附件与正文。
10. 展开输入框后重复；验证 1440×900、375×812、768×1024 的浅色/深色主题。预期窗口可见、列表可滚动，发送按钮不被长技能名挤出屏幕。
11. 使用 100/1000 个候选检查持续输入及方向键定位末项。预期只渲染附近的有限行；搜索 p95 小于 16ms，不出现逐键网络请求。

自动验证：`pnpm run test:unit` 包含 token 边界、键盘选择、中文搜索、粘贴与关闭抑制测试。实际 UI 截图和请求/性能记录位于 `output/playwright/0190-*`。

清理/回退：清空虚构会话草稿和测试附件；关闭测试会话。需要回退时切换保留的 0.1.89 候选镜像，不修改生产认证或历史会话。

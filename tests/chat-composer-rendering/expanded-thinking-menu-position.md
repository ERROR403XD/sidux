# 展开输入框的思考强度菜单定位

前提：4173 使用当前代码；选择一个可用模型，输入框没有录音或其他阻塞操作。

1. 在 1440×900 浅色、深色主题中展开输入框，点击思考强度。
2. 确认菜单紧贴触发按钮上方，左边对齐按钮；临近视口右边界时向内收敛，不叠加侧边栏宽度。
3. 选择“高”，确认选项被应用且菜单关闭；重新打开后点击页面空白处应关闭。
4. 收起输入框后重复操作；测试模型菜单的搜索、选择和取消。
5. 在 375×812 浅/深色、768×1024 深色下重复，菜单应完整处于视口内，展开输入框不挤出发送按钮。

实现原因：展开布局的 `contain: layout` 建立 fixed 定位包含块；菜单的视口坐标此前被重复偏移。菜单通过 Teleport 挂到 body，点击外部的检测同时认可菜单本身。

性能：只读按钮和菜单尺寸，每次打开及已有 resize/scroll 事件更新位置；不增加 API。Playwright 实测五种视口/主题打开菜单 API=0。

清理：恢复原思考强度、收起输入框，关闭临时测试页；不发送测试请求或变更生产服务。

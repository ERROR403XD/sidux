# 扩展的项目范围、有效状态与刷新

## 前提

使用隔离的 59001 或当前源码 4173，CLI 0.153.4。准备含同名用户/项目技能的测试目录、本地相对路径插件市场，以及 stdio MCP 夹具；保留原用户配置。外部 OAuth 不作为本用例前提。

## 操作与预期

1. 从会话进入技能，分别打开插件、应用和技能页。范围保留来源目录和会话，插件查询带 cwd，Apps/MCP 带 threadId；刷新后范围相同；若 CLI 重启导致来源会话未载入，明确提示先返回会话，不偷偷恢复任务。改选“全局”后清除来源会话，项目技能消失。仅目录范围明示 Apps/MCP 使用全局配置。
2. 查看同名技能：按各自路径显示，项目、用户和插件来源可区分。仅用户非插件技能提供卸载。一个技能禁用不改变同名另一路径；失败不先改变开关，不触发 GitHub 推送。
3. 延迟项目技能响应，改选全局后释放旧响应；旧条目不能覆盖全局列表。技能读取失败显示实际错误，刷新后恢复，不能把磁盘存在伪装为已启用。
4. 查看已连接但不可调用的 App、可调用 App 和有效配置禁用项。安装/连接、目录启用与运行快照状态分别显示；状态接口失败/缺失为未知；目录接口 403 等失败只显示简短错误，仍能读取的运行快照单独显示，不展示错误 HTML，不显示缺少目录元数据的安装/启停按钮。修改用户开关后重新读取有效状态，不能只靠本地勾选。
5. 安装本地插件，禁用、刷新再卸载。每次后续 plugin/list 绕过缓存，详情同步，技能菜单刷新。按原生策略标注不可用项。
6. MCP 已登录但连接失败时同时显示两个状态；禁用、启动中等不伪装为连接成功。普通列表只读 toolsAndAuthOnly，浏览器响应不含 inputSchema；展开后读取资源。普通“刷新”不重载配置，“重载 MCP 配置”明确调用一次重载再读状态。
7. 原生 MCP 状态通知、重连或返回窗口时刷新当前可见范围；首次账号快照返回不重建目录页，同范围正在进行的请求合并，切换/卸载后旧响应不覆盖新页面。分页返回重复游标时停止并报错。
8. 1440×900、768×1024、375×812 各检查浅深主题、实际卡片和详情，截图在 output/playwright。无横向溢出、浅色大块表面或脚本错误。

## 清理与回退

仅移除本用例创建的临时容器和目录。还原测试技能启用设置或卸载 fixture 插件，不删除用户目录或认证卷。59001 应用回退到已验收 0.2.5 镜像时保留独立用户状态；生产 5900 不操作。

### 0.2.15 官方详情 404 与管理链接

前置：59001 中已连接 Gmail、Google Drive；只读验证，不安装/卸载、重新授权或发送邮件。错误界面另用 4173 请求拦截验证浅深主题。
1. 打开 Gmail、Google Drive，插件详情成功返回；“在 ChatGPT 中管理”指向官方插件详情页。仅替换已核实的两个旧 `/apps/...` 地址，未知地址及新版链接保持原值。
2. 在候选应用真实会话调用 Gmail profile 和 Drive 搜索（最多一条元数据），实际工具状态 completed 后才记录连接成功；不读取正文、不在报告中记录账号或文件信息。
3. 模拟 `plugin/read` 包装的官方目录 HTTP 404；界面显示“官方插件详情暂不可用（404），请稍后重试。”及已有摘要，提供重试，已安装插件仍可启停。重试仅增加一次详情请求。
4. 普通本地 404 不能被误报为官方插件详情故障；已有连接可用性不能从详情 404 推断。
5. 官方管理页需要浏览器自己的 ChatGPT 登录态；未登录情况下只验证链接目标，不声称完成登录后的管理操作。
清理：关闭测试会话与浏览器上下文，保留只含工具名称/状态/成功标记的验收记录。

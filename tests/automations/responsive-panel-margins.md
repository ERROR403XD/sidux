# 自动化页面最小外侧间距

前置条件：59001 候选版本，至少一项自动化；分别选择明暗主题。

1. 打开自动化页面，把窗口由 1440px 缩到 768px、375px，并反向扩大。
2. 检查面板与内容区左右边界均至少相距 12px；宽屏仍居中，最大宽度保持原值。
3. 检查标题与操作按钮可以换行，无水平溢出，列表滚动与编辑入口可用。

预期：两侧间距不被挤掉，明暗主题表面颜色正确，调整宽度不触发调度或账号请求。

自动验证：`node scripts/test-project-organization-ui.cjs`；1440x1000、768x1024、375x812 × 明暗主题，测量真实 `.automations-panel` 边界与页面 scrollWidth。结果位于 `output/0219-final/project-ui.json`，截图位于 `output/playwright/0219-automations-margin-*.png`。

性能：仅增加宽度约束及工具栏换行，复用原有布局；不添加 JS、监听器或数据请求。浏览器记录验证缩放无新增变更请求。

清理：浏览器脚本使用拦截的临时 API 数据，结束时关闭自己的浏览器；人工检查不要执行不必要的自动化。回退只撤销相应 CSS 规则。
